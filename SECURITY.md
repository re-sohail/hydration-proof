# Security

Please report vulnerabilities privately through GitHub security advisories on https://github.com/re-sohail/hydration-proof, not in public issues.

What hydration-proof does and does not do:

- It runs only on your machine or CI runner and sends nothing anywhere. There is no telemetry.
- It starts the command you configure and opens the URLs you test in a local browser.
- Reports can contain page text, attribute values and URLs of the tested app. Treat them like test artifacts of that app.
