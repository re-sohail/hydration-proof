# Examples

Each folder is a recipe you can copy into your own project: a config, a workflow
or a plugin, with a README that says what it is for and what to change. Nothing
here needs installing — they are files, not packages.

| Example | For |
| --- | --- |
| [next-app-router](next-app-router/) | The starting point: a Next.js app, discovered routes, one command |
| [signed-in](signed-in/) | Public, customer and admin pages in one run |
| [environment-matrix](environment-matrix/) | Locales, timezones, themes, screens and browsers |
| [github-actions](github-actions/) | Pull-request annotations, a baseline, sharding and artifacts |
| [monorepo](monorepo/) | Several apps in one repository, one combined report |
| [custom-plugin](custom-plugin/) | Teaching the tool about your own libraries and infrastructure |
| [existing-playwright](existing-playwright/) | Reusing the Playwright setup, browsers and login you already have |

The full reference is in [the documentation](../docs/README.md); these are the
shapes that come up most often.
